# Référence visuelle verrouillée — interface professeur

La capture `docs/reference-interface-professeur.png` est la référence visuelle prioritaire de l'interface professeur.

Principes à conserver :

- bandeau institutionnel blanc avec logo Académie d'Aix-Marseille + logo établissement ;
- titre long de la progression et identité de l'équipe enseignante dans le bandeau supérieur ;
- actions professeur à droite (profil, déconnexion, ajout) ;
- navigation principale par onglets colorés : Progression, Élèves, Évaluations, PFMP, Synthèse compétences, CCF, Accès élève ;
- progression annuelle horizontale avec navigation début/fin et déplacement horizontal ;
- colonnes de périodes à en-têtes très colorés et cartes blanches ;
- PFMP matérialisées comme des colonnes étroites jaunes insérées dans la progression ;
- cartes avec liseré couleur par groupe de compétences, badges niveau/statut, enseignant, durée, possibilité de modifier et d'évaluer les élèves ;
- commandes de déplacement haut/bas dans chaque colonne ;
- ergonomie dense mais lisible, pensée pour écran d'ordinateur et tablette.

La version multi-prof ajoute les comptes, classes multiples, rôles, réglages et droits sans remplacer cette ergonomie de référence.
