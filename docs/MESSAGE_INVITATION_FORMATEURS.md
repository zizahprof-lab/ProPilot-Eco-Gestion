# Message d’invitation — pilote ProPilot

Bonjour,

Je vous propose de tester **ProPilot Eco-Gestion**, un outil que je développe pour faciliter le suivi pédagogique en lycée professionnel : progression, compétences, évaluations, PFMP, CCF, documents et travail en équipe.

Vous faites partie d’un premier groupe de **10 formateurs académiques**. L’objectif n’est pas seulement de vérifier que l’outil fonctionne, mais surtout d’avoir votre regard professionnel sur son ergonomie et sa pertinence pédagogique.

Le lien du pilote vous sera transmis dès l’ouverture. Pour cette phase, l’inscription se fait avec votre adresse **@ac-aix-marseille.fr**. Après inscription, le compte doit être approuvé par l’administrateur avant l’accès aux classes.

Une rubrique **Bugs / RETEX** est intégrée directement dans ProPilot pour signaler un problème ou proposer une amélioration.

Pour le premier essai, merci d’utiliser de préférence quelques élèves fictifs.

Merci d’avance pour vos retours.
