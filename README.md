# ProPilot Eco-Gestion

Application pédagogique pour le suivi des classes de Bac Pro métiers du commerce et de la vente.

## État
Version de travail avant pilote multi-professeurs.

Le projet conserve l’ergonomie et les fonctions de la version professeur de référence, avec en plus :
- gestion multi-classes et multi-professeurs ;
- rôles propriétaire, co-propriétaire, éditeur et lecture seule ;
- progression P1 à P7 avec PFMP ;
- évaluations, synthèses et positionnement ;
- CCF et dossiers documentaires ;
- espace élève configurable ;
- sécurité et stockage via Supabase.

> Dépôt public : aucun mot de passe, clé privée ou donnée nominative élève ne doit être versionné.
